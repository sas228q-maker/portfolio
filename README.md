# Портфоліо — сайти для бізнесу в Дубні

Статичний сайт-портфоліо + 4 демо-сайти для різних ніш. Без збірки, без залежностей —
чистий HTML/CSS/JS, відкривається навіть локально подвійним кліком.

## Що всередині

| Файл | Що це |
|---|---|
| `index.html` | Головна сторінка портфоліо: послуги, процес, 4 роботи з живим прев'ю |
| `demo-beauty/index.html` | Демо: салон краси та барбершоп — онлайн-запис, прайс, майстри, галерея |
| `demo-cafe/index.html` | Демо: кав'ярня та ресторан — меню з категоріями, бронювання, доставка |
| `demo-auto/index.html` | Демо: автосервіс і СТО — прайс, калькулятор вартості, запис |
| `demo-dental/index.html` | Демо: стоматологія — послуги, лікарі, FAQ, запис на прийом |
| `assets/base.css` | Дизайн-система: теми, сітки, картки, форми, адаптив |
| `assets/app.js` | Інтерактив: меню-таби, форми, калькулятор, анімації, прев'ю |

## Як опублікувати на GitHub Pages

Файли мають лежати **в корені репозиторію** (щоб `index.html` відкривався одразу).

```bash
# 1. Створити порожній репозиторій на github.com (без README), назва будь-яка,
#    наприклад portfolio
# 2. У цій папці:
git remote add origin git@github.com:ТВІЙ_НІК/portfolio.git
git branch -M main
git push -u origin main
# 3. На GitHub: Settings -> Pages -> Source: Deploy from a branch
#    Branch: main, папка: / (root) -> Save
```

Через 1–2 хвилини сайт буде доступний за адресою
`https://ТВІЙ_НІК.github.io/portfolio/`

## Як персоналізувати демо під конкретний заклад

У розмітці назва, телефон, адреса та Instagram помічені атрибутами
`data-var="name"`, `data-var="phone"`, `data-var="address"`, `data-var="instagram"`.
Скрипт `../scripts/build_demo_for_lead.py` підставляє туди дані реального закладу —
і виходить демо з його назвою, яке можна показати в першому ж повідомленні.

## Локальний перегляд

Просто відкрий `index.html` у браузері. Прев'ю робіт на головній — це `<iframe>`,
які у `file://` можуть не показати вміст у деяких браузерах. Щоб побачити все як на
сервері, запусти в цій папці:

```bash
python -m http.server 8000
# і відкрий http://localhost:8000
```

## Примітки

- Усі зображення — CSS-градієнти та SVG, тому сайт важить кілограми, а не мегабайти
  й не залежить від зовнішніх CDN.
- Форми поки що не мають бекенду: показують підтвердження на клієнті.
  Для реального закладу підключається Telegram-бот або Google Forms — 15 хвилин роботи.
